# Parjamie

A two-player cross-and-circle race game for iPhone, installed directly from Xcode.

## Rules for this project

- **Never use the trademarked name of the commercial board game this is based on**, or its close spellings. That name is owned by another company. This applies to on-screen text, the home screen name, the icon, code comments, test names, commit messages, and documentation. Describe the game generically instead, such as "the race home" or "cross-and-circle game". `Tests/ParjamieEngineTests/NamingTests.swift` fails if the name shows up in the project.
- **The look is a welding shop on the traditional cross-and-circle layout** (Jamie is a professional welder). Diamond-plate steel track, a weld bead around the cross, tack-weld crosses on the castles, painted floor bays with hazard brackets for the nests, a bolted flange with torch flames at home, welding-helmet pawns whose lenses light up when movable, and machined steel dice. Game moments are welding-themed too: blockades drawn as welded together, spark bursts on captures, "Overheated!" for three doubles, and a "Certified Welder" plate for the winner. Avoid the commercial game's trade dress: a square board with solid colored corner circles, its logo, or its box art.
